# Dorm Packer 3000

A retro desktop-styled dorm packing list. Check items off, group them into
categories, and tag them with color-coded labels — all in a single HTML file
with no dependencies. Your list saves automatically in the browser
(localStorage).

## Features

- ✅ Checkboxes with a live "packed" progress meter
- 📁 Collapsible categories/groups (add your own)
- 🏷️ Color-coded labels/tags (add your own)
- 🔎 Filter items by label
- 💾 Auto-saves to the browser — no account, no server
- 🗑️ Delete items, groups, and labels; reset to the starter list

## Usage

Open `dorm-packer.html` in any browser. That's it.

## Tech

Plain HTML, CSS, and vanilla JavaScript in one file. Warm, muted retro
"desktop OS" aesthetic.
